# Solutions — Polynomials

Matches problem numbers in `practice-problems.md`.

## Easy

**S1.** `(2x² + 3x + 1) + (4x² - x + 5)`
- Group: `(2x² + 4x²) + (3x - x) + (1 + 5)`
- **Answer: 6x² + 2x + 6**

**S2.** `(6x² - 2x + 3) - (2x² + x - 1)`
- Distribute the negative: `6x² - 2x + 3 - 2x² - x + 1`
- Group: `(6x² - 2x²) + (-2x - x) + (3 + 1)`
- **Answer: 4x² - 3x + 4**

**S3.** `(x³ + 2x - 4) + (3x³ - x + 6)`
- Group: `(x³ + 3x³) + (2x - x) + (-4 + 6)`
- **Answer: 4x³ + x + 2**

**S4.** `4x(x + 3)`
- Distribute: `4x · x = 4x²`, `4x · 3 = 12x`
- **Answer: 4x² + 12x**

**S5.** `(5x - 7) - (2x - 3)`
- Distribute the negative: `5x - 7 - 2x + 3`
- Group: `(5x - 2x) + (-7 + 3)`
- **Answer: 3x - 4**

## Medium

**S6.** `-2x²(3x - 4)`
- Distribute: `-2x² · 3x = -6x³`, `-2x² · (-4) = 8x²`
- **Answer: -6x³ + 8x²**

**S7.** `(x + 2)(x + 6)` — FOIL
- First: `x·x = x²`; Outer: `x·6 = 6x`; Inner: `2·x = 2x`; Last: `2·6 = 12`
- Combine: `x² + 6x + 2x + 12`
- **Answer: x² + 8x + 12**

**S8.** `(x - 4)(x + 9)` — FOIL
- First: `x·x = x²`; Outer: `x·9 = 9x`; Inner: `-4·x = -4x`; Last: `-4·9 = -36`
- Combine: `x² + 9x - 4x - 36`
- **Answer: x² + 5x - 36**

**S9.** `(2x² - 3x + 5) + (x² + 4x - 2) + (-3x² + x - 1)`
- Group x² terms: `2x² + x² - 3x² = 0`
- Group x terms: `-3x + 4x + x = 2x`
- Group constants: `5 - 2 - 1 = 2`
- **Answer: 2x + 2**

**S10.** `(x - 3)(x - 7)` — FOIL
- First: `x·x = x²`; Outer: `x·(-7) = -7x`; Inner: `-3·x = -3x`; Last: `-3·(-7) = 21`
- Combine: `x² - 7x - 3x + 21`
- **Answer: x² - 10x + 21**

## Hard

**S11.** `(x + 2)(x² - 3x + 4)`
- Distribute `x` across the trinomial: `x³ - 3x² + 4x`
- Distribute `2` across the trinomial: `2x² - 6x + 8`
- Add: `x³ - 3x² + 4x + 2x² - 6x + 8`
- Combine like terms: `x³ + (-3x² + 2x²) + (4x - 6x) + 8`
- **Answer: x³ - x² - 2x + 8**

**S12.** `(2x + 1)(3x - 5)` — FOIL
- First: `2x·3x = 6x²`; Outer: `2x·(-5) = -10x`; Inner: `1·3x = 3x`; Last: `1·(-5) = -5`
- Combine: `6x² - 10x + 3x - 5`
- **Answer: 6x² - 7x - 5**

**S13.** `(4x² + 3x - 2) - 2(x² - 5x + 3)`
- Distribute the `-2`: `4x² + 3x - 2 - 2x² + 10x - 6`
- Group: `(4x² - 2x²) + (3x + 10x) + (-2 - 6)`
- **Answer: 2x² + 13x - 8**

**S14.** `(x + 5)²` means `(x + 5)(x + 5)` — FOIL
- First: `x·x = x²`; Outer: `x·5 = 5x`; Inner: `5·x = 5x`; Last: `5·5 = 25`
- Combine: `x² + 5x + 5x + 25`
- **Answer: x² + 10x + 25**

**S15.** `(x - 6)(x + 6)` — FOIL
- First: `x·x = x²`; Outer: `x·6 = 6x`; Inner: `-6·x = -6x`; Last: `-6·6 = -36`
- Combine: `x² + 6x - 6x - 36` — the middle terms cancel out
- **Answer: x² - 36**
