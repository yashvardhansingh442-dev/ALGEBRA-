# Practice Problems — Polynomials

Solutions are in `solutions.md` — try each problem before checking.

## Easy

**P1.** Add: `(2x² + 3x + 1) + (4x² - x + 5)`
**P2.** Subtract: `(6x² - 2x + 3) - (2x² + x - 1)`
**P3.** Add: `(x³ + 2x - 4) + (3x³ - x + 6)`
**P4.** Multiply: `4x(x + 3)`
**P5.** Subtract: `(5x - 7) - (2x - 3)`

## Medium

**P6.** Multiply: `-2x²(3x - 4)`
**P7.** FOIL: `(x + 2)(x + 6)`
**P8.** FOIL: `(x - 4)(x + 9)`
**P9.** Add all three: `(2x² - 3x + 5) + (x² + 4x - 2) + (-3x² + x - 1)`
**P10.** FOIL: `(x - 3)(x - 7)`

## Hard

**P11.** Multiply a binomial by a trinomial: `(x + 2)(x² - 3x + 4)`
**P12.** FOIL with coefficients: `(2x + 1)(3x - 5)`
**P13.** Distribute and subtract: `(4x² + 3x - 2) - 2(x² - 5x + 3)`
**P14.** Square a binomial: `(x + 5)²`
**P15.** Multiply: `(x - 6)(x + 6)`

*Notice P14 and P15 follow patterns worth remembering — squaring a binomial, and multiplying a "difference of squares" pair. You'll see these patterns again in Module 06.*
