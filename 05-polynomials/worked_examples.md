# Worked Examples — Polynomials

Cover the solution and try each one yourself first.

---

### Example 1: Classifying a polynomial
**Problem:** State the degree and classify `3x² - 5x + 2`.

**Step 1:** Look at each term's degree: `3x²` (degree 2), `-5x` (degree 1), `2` (degree 0)
**Step 2:** The highest degree present is 2 → **degree 2**
**Step 3:** Count the terms: three terms → **trinomial**

**Answer: Degree 2, trinomial (a quadratic trinomial)**

---

### Example 2: Adding polynomials
**Problem:** Add `(3x² + 2x - 5) + (x² - 4x + 7)`

**Step 1:** Group like terms: `(3x² + x²) + (2x - 4x) + (-5 + 7)`
**Step 2:** Combine each group: `4x² - 2x + 2`

**Answer: 4x² - 2x + 2**

---

### Example 3: Subtracting polynomials
**Problem:** Subtract `(5x² - 3x + 1) - (2x² + 4x - 6)`

**Step 1:** Distribute the negative sign across every term of the second polynomial:
`5x² - 3x + 1 - 2x² - 4x + 6`
**Step 2:** Group like terms: `(5x² - 2x²) + (-3x - 4x) + (1 + 6)`
**Step 3:** Combine: `3x² - 7x + 7`

**Answer: 3x² - 7x + 7**

---

### Example 4: Multiplying by a monomial
**Problem:** `3x(2x² - 5x + 4)`

**Step 1:** Distribute `3x` to each term:
`3x · 2x² = 6x³`
`3x · (-5x) = -15x²`
`3x · 4 = 12x`
**Step 2:** Combine: `6x³ - 15x² + 12x`

**Answer: 6x³ - 15x² + 12x**

---

### Example 5: FOIL (multiplying two binomials)
**Problem:** `(x + 3)(x - 5)`

**Step 1 — First:** `x · x = x²`
**Step 2 — Outer:** `x · (-5) = -5x`
**Step 3 — Inner:** `3 · x = 3x`
**Step 4 — Last:** `3 · (-5) = -15`
**Step 5:** Add all four and combine like terms: `x² - 5x + 3x - 15 = x² - 2x - 15`

**Answer: x² - 2x - 15**
