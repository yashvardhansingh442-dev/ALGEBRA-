# Solutions — Foundations

Matches problem numbers in `practice-problems.md`.

## Easy

**S1.** `-6 + 9 = 3`
**S2.** `4 - (-7) = 4 + 7 = 11`
**S3.** `2 + 3 × 4` → multiplication first: `3 × 4 = 12` → `2 + 12 = 14`
**S4.** `x + 8 = 15` → subtract 8: `x = 7`
**S5.** `x - 6 = -2` → add 6: `x = 4`

## Medium

**S6.** `(-3) × (-4) + 2` → same signs multiply positive: `12 + 2 = 14`
**S7.** `5 + 2 × (6 - 3)²` → parentheses: `(3)² = 9` → `5 + 2 × 9 = 5 + 18 = 23`
**S8.** `2x + 5 = 17` → subtract 5: `2x = 12` → divide by 2: `x = 6`
**S9.** `4x - 9 = -1` → add 9: `4x = 8` → divide by 4: `x = 2`
**S10.** `18 ÷ 3 × 2 - 4` → left to right: `18 ÷ 3 = 6` → `6 × 2 = 12` → `12 - 4 = 8`

## Hard

**S11.** `-2² + 3 × (-4 + 6)³`
- `-2² = -4` (the negative applies after squaring, by convention)
- `(-4 + 6) = 2`, then `2³ = 8`
- `3 × 8 = 24`
- `-4 + 24 = 20`

**S12.** `-3x + 10 = 4x - 4`
- Add 3x to both sides: `10 = 7x - 4`
- Add 4: `14 = 7x`
- Divide by 7: `x = 2`

**S13.** `5 - 2x = 3x + 15`
- Subtract 3x: `5 - 5x = 15`
- Subtract 5: `-5x = 10`
- Divide by -5: `x = -2`

**S14.** `(-5 + 2)² ÷ (1 - 4) × 2`
- `(-5 + 2) = -3`, so `(-3)² = 9`
- `(1 - 4) = -3`
- `9 ÷ (-3) = -3`
- `-3 × 2 = -6`

**S15.** `-(x - 3) + 2x = 9`
- Distribute the negative: `-x + 3 + 2x = 9`
- Combine like terms: `x + 3 = 9`
- Subtract 3: `x = 6`
