# Worked Examples — Inequalities

Cover the solution and try each one yourself first.

---

### Example 1: Basic inequality, positive coefficient
**Problem:** Solve `5x - 3 > 12`

**Step 1:** Add 3 to both sides: `5x > 15`
**Step 2:** Divide by 5 (positive — no flip): `x > 3`

**Answer: x > 3**

---

### Example 2: Negative coefficient — the flip in action
**Problem:** Solve `-3x + 2 ≤ 14`

**Step 1:** Subtract 2 from both sides: `-3x ≤ 12`
**Step 2:** Divide by -3 (negative — flip `≤` to `≥`): `x ≥ -4`

**Check:** Try `x = 0` (should satisfy `x ≥ -4`): `-3(0) + 2 = 2`, and `2 ≤ 14` ✓
Try `x = -10` (should NOT satisfy `x ≥ -4`): `-3(-10) + 2 = 32`, and `32 ≤ 14` is false ✓ (correctly excluded)

**Answer: x ≥ -4**

---

### Example 3: Variables on both sides
**Problem:** Solve `7 - 2x < 3x + 22`

**Step 1:** Subtract `3x` from both sides: `7 - 5x < 22`
**Step 2:** Subtract 7: `-5x < 15`
**Step 3:** Divide by -5 (negative — flip `<` to `>`): `x > -3`

**Answer: x > -3**

---

### Example 4: Distributing first
**Problem:** Solve `4(x - 2) ≥ 2x + 6`

**Step 1:** Distribute: `4x - 8 ≥ 2x + 6`
**Step 2:** Subtract `2x`: `2x - 8 ≥ 6`
**Step 3:** Add 8: `2x ≥ 14`
**Step 4:** Divide by 2 (positive — no flip): `x ≥ 7`

**Answer: x ≥ 7**

---

### Example 5: Compound inequality
**Problem:** Solve `-5 ≤ 3x + 1 < 13`

**Step 1:** Subtract 1 from all three parts: `-6 ≤ 3x < 12`
**Step 2:** Divide all three parts by 3 (positive — no flip): `-2 ≤ x < 4`

**Answer: -2 ≤ x < 4**
