# Advanced Polynomial Algebra Engine

An implementation of computational polynomial algebra using Python.

## Mathematical Concepts

- Polynomial Rings over the Rational Field
- Polynomial Arithmetic
- Euclidean Division Algorithm
- Euclidean Algorithm and Polynomial GCD
- Formal Differentiation and Integration
- Polynomial Composition
- Horner's Evaluation Method
- Lagrange Interpolation

## Mathematical Foundation

The implementation works with polynomials over the rational field Q[x].

Instead of floating-point approximations, it uses exact rational arithmetic through Python's `Fraction` class.

## Objectives

1. Translate algebraic operations into computational algorithms.
2. Understand the mathematical foundations behind polynomial computation.
3. Explore algorithmic implementations of algebraic structures.
4. Build a foundation for symbolic computation systems.

## Requirements

- Python 3.9+
- No external dependencies

## Run

```bash
python polynomial_algebra.py
```
