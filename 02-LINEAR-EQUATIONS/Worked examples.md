# Worked Examples — Linear Equations

Cover the solution and try each one yourself first.

---

### Example 1: Multi-step, one side
**Problem:** Solve `4x + 7 = 23`

**Step 1:** Subtract 7 from both sides: `4x = 16`
**Step 2:** Divide both sides by 4: `x = 4`

**Check:** `4(4) + 7 = 16 + 7 = 23` ✓

**Answer: x = 4**

---

### Example 2: Distributing first
**Problem:** Solve `5(x + 2) = 3x + 20`

**Step 1:** Distribute the left side: `5x + 10 = 3x + 20`
**Step 2:** Subtract `3x` from both sides: `2x + 10 = 20`
**Step 3:** Subtract 10: `2x = 10`
**Step 4:** Divide by 2: `x = 5`

**Check:** `5(5 + 2) = 5(7) = 35`, and `3(5) + 20 = 15 + 20 = 35` ✓

**Answer: x = 5**

---

### Example 3: Variables on both sides, negative coefficient
**Problem:** Solve `7 - 2x = 3x - 8`

**Step 1:** Add `2x` to both sides: `7 = 5x - 8`
**Step 2:** Add 8 to both sides: `15 = 5x`
**Step 3:** Divide by 5: `3 = x`, so `x = 3`

**Check:** `7 - 2(3) = 7 - 6 = 1`, and `3(3) - 8 = 9 - 8 = 1` ✓

**Answer: x = 3**

---

### Example 4: Clearing a fraction
**Problem:** Solve `(x + 4)/2 = 9`

**Step 1:** Multiply both sides by 2: `x + 4 = 18`
**Step 2:** Subtract 4: `x = 14`

**Check:** `(14 + 4)/2 = 18/2 = 9` ✓

**Answer: x = 14**

---

### Example 5: Recognizing "no solution"
**Problem:** Solve `4(x - 1) = 4x + 6`

**Step 1:** Distribute: `4x - 4 = 4x + 6`
**Step 2:** Subtract `4x` from both sides: `-4 = 6`

This is false for any value of `x` — the variable terms cancel out and leave a contradiction.

**Answer: No solution**
