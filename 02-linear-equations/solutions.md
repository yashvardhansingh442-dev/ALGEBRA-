# Solutions — Linear Equations

Matches problem numbers in `practice-problems.md`.

## Easy

**S1.** `x + 9 = 20` → subtract 9: `x = 11`
**S2.** `x - 5 = -3` → add 5: `x = 2`
**S3.** `3x = 21` → divide by 3: `x = 7`
**S4.** `2x - 4 = 10` → add 4: `2x = 14` → divide by 2: `x = 7`
**S5.** `x/4 = 6` → multiply both sides by 4: `x = 24`

## Medium

**S6.** `3(x + 2) = 18`
- Distribute: `3x + 6 = 18`
- Subtract 6: `3x = 12`
- Divide by 3: `x = 4`

**S7.** `6x - 5 = 3x + 10`
- Subtract 3x: `3x - 5 = 10`
- Add 5: `3x = 15`
- Divide by 3: `x = 5`

**S8.** `2(x - 4) = x + 1`
- Distribute: `2x - 8 = x + 1`
- Subtract x: `x - 8 = 1`
- Add 8: `x = 9`

**S9.** `(x - 2)/3 = 5`
- Multiply both sides by 3: `x - 2 = 15`
- Add 2: `x = 17`

**S10.** `4x + 7 = 2x + 19`
- Subtract 2x: `2x + 7 = 19`
- Subtract 7: `2x = 12`
- Divide by 2: `x = 6`

## Hard

**S11.** `3(2x - 1) = 5(x + 3)`
- Distribute both sides: `6x - 3 = 5x + 15`
- Subtract 5x: `x - 3 = 15`
- Add 3: `x = 18`

**S12.** `7 - 3(x - 2) = 2x + 1`
- Distribute: `7 - 3x + 6 = 2x + 1`
- Combine left side: `13 - 3x = 2x + 1`
- Add 3x: `13 = 5x + 1`
- Subtract 1: `12 = 5x`
- Divide by 5: `x = 12/5 = 2.4`

**S13.** `(2x + 1)/3 = (x - 2)/2`
- Cross-multiply: `2(2x + 1) = 3(x - 2)`
- Distribute: `4x + 2 = 3x - 6`
- Subtract 3x: `x + 2 = -6`
- Subtract 2: `x = -8`

**S14.** `5x - 2(x + 3) = 3(x - 1) + 1`
- Distribute: `5x - 2x - 6 = 3x - 3 + 1`
- Simplify: `3x - 6 = 3x - 2`
- Subtract 3x from both sides: `-6 = -2`
- This is false for any x.
- **No solution**

**S15.** `2(x + 3) - 4 = 2x + 2`
- Distribute: `2x + 6 - 4 = 2x + 2`
- Simplify: `2x + 2 = 2x + 2`
- Subtract 2x from both sides: `2 = 2`
- This is true for every x.
- **Infinite solutions**
