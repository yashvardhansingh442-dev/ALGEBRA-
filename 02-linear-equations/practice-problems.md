# Practice Problems — Linear Equations

Solutions are in `solutions.md` — try each problem before checking.

## Easy

**P1.** Solve for x: `x + 9 = 20`
**P2.** Solve for x: `x - 5 = -3`
**P3.** Solve for x: `3x = 21`
**P4.** Solve for x: `2x - 4 = 10`
**P5.** Solve for x: `x/4 = 6`

## Medium

**P6.** Solve for x: `3(x + 2) = 18`
**P7.** Solve for x: `6x - 5 = 3x + 10`
**P8.** Solve for x: `2(x - 4) = x + 1`
**P9.** Solve for x: `(x - 2)/3 = 5`
**P10.** Solve for x: `4x + 7 = 2x + 19`

## Hard

**P11.** Solve for x: `3(2x - 1) = 5(x + 3)`
**P12.** Solve for x: `7 - 3(x - 2) = 2x + 1`
**P13.** Solve for x: `(2x + 1)/3 = (x - 2)/2`
**P14.** Solve for x: `5x - 2(x + 3) = 3(x - 1) + 1`
**P15.** Solve for x: `2(x + 3) - 4 = 2x + 2`

*Note: two of the hard problems don't have a single-number answer — that's intentional. Recognizing "no solution" and "infinite solutions" cases is part of the skill.*
