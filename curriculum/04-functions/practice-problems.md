# Practice Problems — Functions

Solutions are in `solutions.md` — try each problem before checking.

## Easy

**P1.** `f(x) = x + 7`. Find `f(5)`.
**P2.** `f(x) = 3x`. Find `f(-2)`.
**P3.** `f(x) = x²`. Find `f(4)`.
**P4.** `f(x) = 2x - 5`. Find `f(0)`.
**P5.** `f(x) = -x + 10`. Find `f(3)`.

## Medium

**P6.** `f(x) = 2x² + 1`. Find `f(-2)`.
**P7.** `f(x) = 4x - 3`. Find `x` such that `f(x) = 13`.
**P8.** `f(x) = 1/(x - 5)`. State the domain.
**P9.** `f(x) = x² - 4x + 2`. Find `f(3)`.
**P10.** `f(x) = -2x + 7`. Find `x` such that `f(x) = -3`.

## Hard

**P11.** `f(x) = 3x + 2`, `g(x) = x - 1`. Find `f(g(4))`.
**P12.** `f(x) = x² - 2x`. Find `f(a + 1)` in terms of `a` (fully expanded).
**P13.** `f(x) = 2/(x + 3)`. State the domain.
**P14.** `f(x) = x² - 3`, `g(x) = 2x + 1`. Find `g(f(2))`.
**P15.** `f(x) = 3x - 4`, `g(x) = x²`. Find `f(g(-2))`.
