# Practice Problems — Inequalities

Solutions are in `solutions.md` — try each problem before checking.

## Easy

**P1.** Solve for x: `x + 6 > 10`
**P2.** Solve for x: `x - 3 ≤ 7`
**P3.** Solve for x: `2x < 16`
**P4.** Solve for x: `3x ≥ 21`
**P5.** Solve for x: `x/2 > 5`

## Medium

**P6.** Solve for x: `-2x < 8`
**P7.** Solve for x: `3x - 5 ≥ 10`
**P8.** Solve for x: `-4x + 3 > 19`
**P9.** Solve for x: `5x - 2 < 2x + 13`
**P10.** Solve for x: `-x/3 ≤ 2`

## Hard

**P11.** Solve for x: `-2(x - 3) ≥ 4x + 6`
**P12.** Solve for x: `5 - 3x > 2x - 20`
**P13.** Solve for x: `-6 < 2x + 4 ≤ 10`
**P14.** Solve for x: `-3(2x + 1) < 15`
**P15.** Solve for x: `4 - x ≥ 2x - 5`

*Note: several of these require flipping the inequality sign at least once — pay close attention to whether you're dividing by a negative.*
