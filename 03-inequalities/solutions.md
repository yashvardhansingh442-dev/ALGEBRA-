# Solutions — Inequalities

Matches problem numbers in `practice-problems.md`.

## Easy

**S1.** `x + 6 > 10` → subtract 6: `x > 4`
**S2.** `x - 3 ≤ 7` → add 3: `x ≤ 10`
**S3.** `2x < 16` → divide by 2 (positive, no flip): `x < 8`
**S4.** `3x ≥ 21` → divide by 3 (positive, no flip): `x ≥ 7`
**S5.** `x/2 > 5` → multiply both sides by 2 (positive, no flip): `x > 10`

## Medium

**S6.** `-2x < 8`
- Divide by -2 — **negative, flip the sign**: `x > -4`

**S7.** `3x - 5 ≥ 10`
- Add 5: `3x ≥ 15`
- Divide by 3 (positive, no flip): `x ≥ 5`

**S8.** `-4x + 3 > 19`
- Subtract 3: `-4x > 16`
- Divide by -4 — **negative, flip the sign**: `x < -4`

**S9.** `5x - 2 < 2x + 13`
- Subtract 2x: `3x - 2 < 13`
- Add 2: `3x < 15`
- Divide by 3 (positive, no flip): `x < 5`

**S10.** `-x/3 ≤ 2`
- Multiply both sides by -3 — **negative, flip the sign**: `x ≥ -6`

## Hard

**S11.** `-2(x - 3) ≥ 4x + 6`
- Distribute: `-2x + 6 ≥ 4x + 6`
- Subtract 4x: `-6x + 6 ≥ 6`
- Subtract 6: `-6x ≥ 0`
- Divide by -6 — **negative, flip the sign**: `x ≤ 0`

**S12.** `5 - 3x > 2x - 20`
- Subtract 2x: `5 - 5x > -20`
- Subtract 5: `-5x > -25`
- Divide by -5 — **negative, flip the sign**: `x < 5`

**S13.** `-6 < 2x + 4 ≤ 10`
- Subtract 4 from all three parts: `-10 < 2x ≤ 6`
- Divide all three parts by 2 (positive, no flip): `-5 < x ≤ 3`

**S14.** `-3(2x + 1) < 15`
- Distribute: `-6x - 3 < 15`
- Add 3: `-6x < 18`
- Divide by -6 — **negative, flip the sign**: `x > -3`

**S15.** `4 - x ≥ 2x - 5`
- Subtract 2x: `4 - 3x ≥ -5`
- Subtract 4: `-3x ≥ -9`
- Divide by -3 — **negative, flip the sign**: `x ≤ 3`
