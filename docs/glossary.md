# Glossary

Plain-language definitions for the terms used in the **ALGEBRA-** curriculum and code.

- **Part 1** covers algebra terms (used in `curriculum/`).
- **Part 2** covers engine and programming terms (used in `tools/` and `docs/`).

Terms are alphabetical within each part. Each entry has a short definition and, where it helps, a tiny example. The **Level** tag shows where a learner first meets the term (see `curriculum/00-start-here.md`).

> **Contributing a term:** keep the definition to one or two sentences, add an example, and link to the lesson where the term is taught. If a lesson introduces a word that is not here, add it.

## Part 1: Algebra terms

### A

**Absolute value** (Level 1)
The distance of a number from zero, always non-negative. Written |x|.
Example: |−5| = 5 and |5| = 5.

**Arithmetic sequence** (Level 3)
A sequence where each term differs from the previous one by a constant amount (the *common difference*).
Example: 3, 7, 11, 15, ... (difference 4).

### B

**Base** (Level 1)
The number being multiplied in a power.
Example: in 2⁵, the base is 2.

**Binomial** (Level 2)
A polynomial with exactly two terms.
Example: x + 3.

### C

**Coefficient** (Level 1)
The number multiplying a variable.
Example: in 7x², the coefficient is 7.

**Common factor** (Level 2)
A factor shared by every term of an expression. Pulling it out is the first step of most factoring.
Example: in 6x + 9, the common factor is 3, giving 3(2x + 3).

**Complex number** (Level 4)
A number of the form a + bi, where a and b are real and i² = −1.
Example: 3 + 2i.

**Conjugate** (Level 4)
For a + bi, the conjugate is a − bi. Multiplying a complex number by its conjugate gives a real number.
Example: (3 + 2i)(3 − 2i) = 13.

**Constant** (Level 1)
A term or value that does not change and has no variable.
Example: in x² + 5, the constant is 5.

**Constraint** (Level 4)
A condition a solution must satisfy in an optimization problem.
Example: "the surface area must equal 100."

### D

**Degree** (Level 2)
The highest power of the variable in a polynomial.
Example: 4x³ + x − 2 has degree 3.

**Denominator** (Level 1)
The bottom part of a fraction.

**Difference of squares** (Level 2)
The factoring pattern a² − b² = (a − b)(a + b).
Example: x² − 9 = (x − 3)(x + 3).

**Discriminant** (Level 2)
For ax² + bx + c = 0, the quantity b² − 4ac. It tells you how many real solutions exist: positive means two, zero means one, negative means none (two complex).

**Domain** (Level 3)
The set of inputs a function accepts.
Example: the domain of √x is x ≥ 0.

### E

**Equation** (Level 1)
A statement that two expressions are equal, usually containing an unknown to solve for.
Example: 2x + 1 = 9.

**Equivalent expressions** (Level 1)
Expressions that have the same value for every allowed input, even if they look different.
Example: 2(x + 3) and 2x + 6.

**Exponent** (Level 1)
The small raised number telling how many times to multiply the base by itself.
Example: in 2⁵, the exponent is 5.

**Expression** (Level 1)
A combination of numbers, variables, and operations, with no equals sign.
Example: 3x + 2.

### F

**Factor** (Level 2)
*(noun)* A number or expression that divides another evenly. *(verb)* To rewrite something as a product of factors.
Example: x² − 5x + 6 factors as (x − 2)(x − 3).

**Function** (Level 3)
A rule that assigns exactly one output to each input. Written f(x).
Example: f(x) = 2x + 1.

### G

**Geometric sequence** (Level 3)
A sequence where each term is the previous one times a constant (the *common ratio*).
Example: 2, 6, 18, 54, ... (ratio 3).

**Greatest common factor (GCF)** (Level 2)
The largest factor shared by all terms.
Example: GCF of 12x² and 18x is 6x.

### I

**Imaginary unit** (Level 4)
The symbol i, defined by i² = −1.

**Inequality** (Level 1)
A statement comparing expressions with <, >, ≤, or ≥.
Example: 3x − 2 > 7.

**Inverse function** (Level 3)
A function that undoes another: f⁻¹(f(x)) = x.

### L

**Lagrange multiplier** (Level 4)
A technique for optimizing a function subject to a constraint, by introducing an extra variable λ and solving a system built from the gradient of both.

**Like terms** (Level 1)
Terms with the same variable part, which can be combined.
Example: 3x and 5x are like terms; 3x and 5x² are not.

**Linear equation** (Level 1)
An equation whose variable has degree 1.
Example: 4x − 7 = 5.

**Logarithm** (Level 3)
The inverse of exponentiation. log_b(y) = x means bˣ = y.
Example: log₂(8) = 3 because 2³ = 8.

### M

**Matrix** (Level 4)
A rectangular grid of numbers, used to represent linear systems and transformations.

**Monomial** (Level 2)
A polynomial with exactly one term.
Example: 5x³.

### N

**Numerator** (Level 1)
The top part of a fraction.

### O

**Objective function** (Level 4)
The quantity you want to maximize or minimize in an optimization problem.

**Order of operations** (Level 1)
The agreed order for evaluating an expression: parentheses, exponents, multiplication and division (left to right), addition and subtraction (left to right).

### P

**Polynomial** (Level 2)
A sum of terms, each a constant times a variable raised to a whole-number power.
Example: 2x³ − x + 4.

**Power** (Level 1)
A base raised to an exponent, or the result of doing so.

### Q

**Quadratic** (Level 2)
A polynomial of degree 2, or an equation built from one.
Example: x² − 5x + 6 = 0.

**Quadratic formula** (Level 2)
The solution formula for ax² + bx + c = 0: x = (−b ± √(b² − 4ac)) / 2a.

### R

**Radical** (Level 1)
A root expression such as a square root.
Example: √16 = 4.

**Range** (Level 3)
The set of outputs a function can produce.

**Rational expression** (Level 2)
A fraction whose numerator and denominator are polynomials.
Example: (x + 1)/(x² − 4).

**Remainder theorem** (Level 4)
Dividing a polynomial p(x) by (x − a) leaves remainder p(a).

**Root** (Level 2)
A value of the variable that makes an expression equal zero. Also called a *zero*. For equations, a *solution*.
Example: 2 is a root of x² − 5x + 6.

### S

**Sequence** (Level 3)
An ordered list of numbers following a rule.

**Series** (Level 3)
The sum of the terms of a sequence.

**Simplify** (Level 1)
Rewrite an expression in an equivalent but shorter or cleaner form.
Example: 2x + 3x − x simplifies to 4x.

**Solution** (Level 1)
A value that makes an equation true.

**System of equations** (Level 2)
Two or more equations solved together for the same unknowns.
Example: x + y = 5 and x − y = 1 gives x = 3, y = 2.

### T

**Term** (Level 1)
A part of an expression separated by + or −.
Example: 3x² − 5x + 2 has three terms.

**Trinomial** (Level 2)
A polynomial with exactly three terms.

### V

**Variable** (Level 1)
A symbol, usually a letter, standing for a value that can change or is unknown.

**Vieta's formulas** (Level 4)
Relations between a polynomial's coefficients and the sums and products of its roots.
Example: for x² + bx + c, the roots sum to −b and multiply to c.

### Z

**Zero** (Level 2)
See **Root**.

## Part 2: Engine and programming terms

### A

**AST (abstract syntax tree)**
A tree representing the structure of an expression. Each node is a number, a variable, or an operation whose children are its operands.
Example: `2*x + 1` becomes `Add(Mul(Num(2), Var(x)), Num(1))`.

### C

**Canonical form**
See **Normal form**.

**Constant folding**
Evaluating parts of an expression that only involve numbers.
Example: `2 + 3 + x` becomes `5 + x`.

### D

**DomainError**
The exception raised when an operation is mathematically undefined, such as dividing by zero or taking `ln(0)`.

### E

**Exact arithmetic**
Computing with fractions rather than floating-point decimals, so results are not rounded. The engine uses Python's `Fraction` for this.
Example: `1/3 + 1/3 + 1/3` is exactly `1`.

### F

**Flattening**
Merging nested sums or products into one n-ary node.
Example: `Add(a, Add(b, c))` becomes `Add(a, b, c)`.

**Frozen dataclass**
A Python dataclass declared with `frozen=True`, which makes instances immutable. All AST nodes use this.

### H

**Hypothesis**
A Python library for property-based testing. It generates many random inputs and checks that a stated property always holds.

### I

**Idempotence**
A property where applying an operation twice gives the same result as applying it once.
Example: `simplify(simplify(e)) == simplify(e)`.

**Immutable**
Cannot be changed after creation. Immutable AST nodes mean a rewrite rule builds a new tree instead of editing one that other code may still be using.

**Implicit multiplication**
Multiplication written without an operator, as in `2x` or `3(x + 1)`. The parser has to detect and insert it.

### N

**N-ary node**
A node with any number of children, as opposed to exactly two (binary). `Add` and `Mul` are n-ary.

**Normal form**
The single canonical shape that `simplify` produces, so that equivalent expressions end up looking identical. See `ARCHITECTURE.md` section 3.4.

**NotSupportedError**
The exception raised when the engine cannot handle a request (for example, solving a degree-5 polynomial exactly). It never returns a silently wrong answer.

**Numeric cross-check**
A test technique that evaluates the original and the transformed expression at many random points and asserts that the results agree. It checks *meaning*, not shape.

### P

**ParseError**
The exception raised for malformed input, carrying the position of the problem.

**Parser**
The stage that turns a list of tokens into an AST.

**Precedence climbing**
A parsing technique that handles operator precedence and associativity with a simple loop and a table of binding strengths.

**Printer**
The stage that turns an AST back into readable text or LaTeX.

**Property-based test**
A test that states a general rule ("for every expression, X holds") and lets a tool generate the examples, rather than listing fixed cases.

**Pure function**
A function whose output depends only on its inputs and which has no side effects. Every engine stage is meant to be pure.

### R

**Rewrite rule**
A function that transforms an expression when a pattern matches, and does nothing (returns `None`) when it does not.
Example: the rule `x * 1 → x`.

**Round trip**
Converting something to another form and back, expecting the original. Example: `parse(print(e)) == e`.

### S

**Seed**
A starting value for a random number generator. Using the same seed reproduces the same practice problems.

**Step trace**
The recorded list of rewrite rules applied to reach a result, each with its before and after expression. This is what lets the engine explain its work.

### T

**Token**
The smallest meaningful unit of an expression string: a number, a variable name, an operator, or a parenthesis.

**Tokenizer**
The first stage. It turns a string into a list of tokens.
Example: `"2x+1"` becomes `[2, x, +, 1]`.

### U

**Unit test**
A test with a fixed input and an expected output for one function or module.
