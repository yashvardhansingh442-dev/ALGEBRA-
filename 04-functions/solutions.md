# Solutions — Functions

Matches problem numbers in `practice-problems.md`.

## Easy

**S1.** `f(5) = 5 + 7 = 12`
**S2.** `f(-2) = 3(-2) = -6`
**S3.** `f(4) = 4² = 16`
**S4.** `f(0) = 2(0) - 5 = -5`
**S5.** `f(3) = -(3) + 10 = 7`

## Medium

**S6.** `f(-2) = 2(-2)² + 1 = 2(4) + 1 = 8 + 1 = 9`

**S7.** `f(x) = 13` means `4x - 3 = 13`
- Add 3: `4x = 16`
- Divide by 4: `x = 4`

**S8.** Denominator is zero when `x - 5 = 0` → `x = 5`
- **Domain: x ≠ 5** (all real numbers except 5)

**S9.** `f(3) = 3² - 4(3) + 2 = 9 - 12 + 2 = -1`

**S10.** `f(x) = -3` means `-2x + 7 = -3`
- Subtract 7: `-2x = -10`
- Divide by -2: `x = 5`

## Hard

**S11.** `f(g(4))`
- First: `g(4) = 4 - 1 = 3`
- Then: `f(3) = 3(3) + 2 = 9 + 2 = 11`

**S12.** `f(a + 1) = (a + 1)² - 2(a + 1)`
- Expand `(a + 1)² = a² + 2a + 1`
- Expand `2(a + 1) = 2a + 2`
- Combine: `a² + 2a + 1 - 2a - 2 = a² - 1`
- **Answer: a² - 1**

**S13.** Denominator is zero when `x + 3 = 0` → `x = -3`
- **Domain: x ≠ -3** (all real numbers except -3)

**S14.** `g(f(2))`
- First: `f(2) = 2² - 3 = 4 - 3 = 1`
- Then: `g(1) = 2(1) + 1 = 3`

**S15.** `f(g(-2))`
- First: `g(-2) = (-2)² = 4`
- Then: `f(4) = 3(4) - 4 = 12 - 4 = 8`
